# Architecture Agent Workflow

## Role
Design System, UX, Mobile Optimization.

## Responsibilities
1. **Component Audit**: Regularly audit `components/` for reusability.
2. **Style Enforcement**: Enforce Tailwind best practices (avoid magic numbers).
3. **Mobile Responsiveness**: Check mobile responsiveness for new features.
4. **Visual Enhancements**: Suggest visual enhancements (animations, transitions).
